# 🎭 Visual Novel Engine

**Движок для визуальных новелл на Python + Pygame-CE.**

Пишешь историю в JSON — движок делает всё остальное: показывает спрайты, играет музыку, анимирует переходы, обрабатывает выборы и сохраняет прогресс.

## ✨ Возможности

| Категория | Что умеет |
|-----------|-----------|
| **Меню** | Главное меню, выбор истории, настройки, пауза, слоты сохранений |
| **Персонажи** | Спрайты с эмоциями, плавный вход/выход, подсветка говорящего, bounce |
| **Фоны** | Картинки и градиенты, плавный кроссфейд между сценами |
| **Диалоги** | Печатающийся текст, автоперенос строк, имя говорящего в рамке |
| **Эффекты** | Тряска экрана, флеши, взрывы, кровь, глитч, виньетка |
| **Частицы** | Снег, дождь, пепел, сакура, светлячки, искры, кровь |
| **Выборы** | Кнопки с плавным появлением, изменение доверия и флагов |
| **Ветвления** | Узел `branch` — переход по флагам, переменным, доверию |
| **Сохранения** | 6 слотов + автосейв, отдельная папка на каждую историю |
| **Горячая перезагрузка** | Изменил JSON — движок подхватил за секунду (F2) |

## 🚀 Установка

### 1. Python 3.10+

Скачай с [python.org](https://www.python.org/downloads/). При установке отметь **«Add Python to PATH»**.

Проверка:
```bash
python --version
```

### 2. Установка движка

```bash
git clone https://github.com/твой-юзер/vn-engine.git
cd vn-engine
pip install pygame-ce
```

> **Важно:** используем `pygame-ce` (Community Edition), а не обычный `pygame` — он работает на новых версиях Python (3.13, 3.14, 3.15).

### 3. Запуск

```bash
python main.py
```

## ⚡ Быстрый старт

1. Создай папку для своей истории:
   ```
   stories\my_story\
   ```

2. Положи туда файл `story.json`:
   ```json
   {
     "start": "intro",
     "nodes": [
       {
         "id": "intro",
         "type": "scene",
         "bg_color": [30, 30, 50],
         "bg_color_bottom": [10, 10, 20],
         "particles": "snow",
         "characters": [],
         "next": "hello"
       },
       {
         "id": "hello",
         "type": "line",
         "speaker": "Рассказчик",
         "text": "Привет, мир!",
         "name_color": [140, 180, 220],
         "next": "hello"
       }
     ]
   }
   ```

3. Запусти игру:
   ```bash
   python main.py
   ```

4. В главном меню выбери **«Выбрать историю»** → `my_story`.

## ✍️ Как создавать свои истории

### Шаг 1. Создай папку истории

```
stories\my_story\
```

Внутри — минимум `story.json`. Опционально `meta.json` и папка `assets/`.

### Шаг 2. Создай `meta.json`

```json
{
  "title": "Моя история",
  "author": "Твоё имя",
  "description": "Краткое описание",
  "cover": "assets/images/cover.png"
}
```

### Шаг 3. Создай `story.json`

Структура:
```json
{
  "start": "первый_узел",
  "nodes": [
    { "id": "...", "type": "...", ... },
    { "id": "...", "type": "...", ... }
  ]
}
```

**Ключ `start`** — с какого узла начать. **Массив `nodes`** — все сцены, реплики и выборы.

### Шаг 4. Складывай ассеты в `assets/`

```
stories\my_story\assets\
├── images\      # фоны и картинки
├── sprites\     # спрайты персонажей
└── audio\       # музыка и звуки
```

В JSON пути указываются **относительно папки истории**:
```json
"background": "assets/images/room.jpg"
```

### Шаг 5. Запусти и проверь

Выбираешь историю в главном меню — играешь.

**Совет:** пока пишешь, держи игру запущенной. Сохранил JSON — движок сам подхватит изменения через 1 секунду. Если менял картинки — нажми **F2**.

## 📖 Справочник по JSON

### Типы узлов

| `type` | Что делает |
|--------|-----------|
| `scene` | Меняет фон, музыку, частицы, персонажей. Автоматически идёт к `next` |
| `line` | Показывает реплику |
| `choice` | Показывает кнопки выбора |
| `branch` | Условный переход (без показа игроку) |
| `end` | Возврат в главное меню |

---

### Узел `scene`

```json
{
  "id": "scene_1",
  "type": "scene",
  "background": "assets/images/room.jpg",
  "bg_color": [30, 30, 50],
  "bg_color_bottom": [10, 10, 20],
  "particles": "snow",
  "music": "assets/audio/bg.ogg",
  "characters": [
    {
      "name": "Макс",
      "side": "right",
      "color": [240, 190, 90],
      "emotion": "happy",
      "images": {
        "neutral": "assets/sprites/max_neutral.png",
        "happy": "assets/sprites/max_happy.png"
      }
    }
  ],
  "next": "scene_1_1"
}
```

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `background` | нет | Путь к картинке фона |
| `bg_color` | нет | Верхний цвет градиента `[r, g, b]` |
| `bg_color_bottom` | нет | Нижний цвет градиента |
| `particles` | нет | `snow`, `rain`, `ash`, `sakura`, `fireflies`, `none` |
| `music` | нет | Путь к музыкальному файлу |
| `characters` | нет | Массив персонажей |
| `next` | да | id следующего узла |

**Приоритет:** если есть `background` — берётся картинка. Иначе — градиент по `bg_color`.

---

### Узел `line`

```json
{
  "id": "line_1",
  "type": "line",
  "speaker": "Макс",
  "text": "Привет! Как дела?",
  "name_color": [240, 190, 90],
  "emotion": "happy",
  "effect": "shake",
  "next": "line_2"
}
```

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `speaker` | да | Имя говорящего |
| `text` | да | Текст реплики |
| `name_color` | нет | Цвет имени `[r, g, b]`. По умолчанию розовый |
| `emotion` | нет | Эмоция говорящего (переключает спрайт) |
| `effect` | нет | Экранный эффект (см. ниже) |
| `next` | да | id следующего узла |

**Бонус:** в `line` можно менять фон, музыку, частицы и персонажей — движок применит их прямо перед показом реплики:

```json
{
  "id": "line_1",
  "type": "line",
  "speaker": "Рассказчик",
  "text": "Он вошёл в комнату.",
  "background": "assets/images/room.jpg",
  "particles": "rain",
  "next": "line_2"
}
```

---

### Узел `choice`

```json
{
  "id": "choice_1",
  "type": "choice",
  "options": [
    {
      "text": "Согласиться",
      "flag": "agreed",
      "trust": {"Макс": 10},
      "set_var": {"смелость": 1},
      "next": "agreed_scene"
    },
    {
      "text": "Отказаться",
      "trust": {"Макс": -5},
      "next": "refused_scene"
    }
  ]
}
```

Каждая опция:

| Поле | Описание |
|------|----------|
| `text` | Текст на кнопке |
| `flag` | Установить флаг (для будущих `branch`) |
| `trust` | Изменить доверие: `{"Имя": +10}` |
| `set_var` | Установить переменную: `{"hp": 100}` |
| `next` | Куда идти после выбора |
| `sfx` | Путь к звуку клика (опционально) |

---

### Узел `branch`

Автоматический переход по условию. **Игрок не видит кнопок** — движок сам выбирает путь.

```json
{
  "id": "check_ending",
  "type": "branch",
  "cases": [
    {
      "requires": "friend_max",
      "next": "good_ending"
    },
    {
      "requires": "killed_boss",
      "trust": {"Макс": {"op": ">=", "value": 50}},
      "next": "mixed_ending"
    },
    {
      "var": {"name": "hp", "op": "<", "value": 20},
      "next": "bad_ending"
    }
  ],
  "default": "neutral_ending"
}
```

Условия в `case`:

| Поле | Что проверяет |
|------|---------------|
| `requires` | Флаг установлен |
| `not_flag` | Флага НЕТ |
| `var` | Переменная: `{"name": "hp", "op": ">", "value": 50}` |
| `trust` | Доверие: `{"Макс": {"op": ">=", "value": 30}}` |

Операторы: `==`, `!=`, `>`, `<`, `>=`, `<=`

**Логика:** движок идёт по списку `cases` сверху вниз. Первое совпавшее — выигрывает. Если ничего не сработало — идёт в `default`.

## 🎨 Эффекты и анимации

### Экранные эффекты (`effect` в `line`)

| Значение | Что делает |
|----------|-----------|
| `"shake"` | Тряска экрана |
| `"flash"` | Белая вспышка |
| `"explosion"` | Сильная тряска + красный флеш + искры |
| `"blood"` | Брызги крови из центра |
| `"glitch"` | Глитч-полосы |

Пример:
```json
{
  "id": "bomb",
  "type": "line",
  "speaker": "Рассказчик",
  "text": "И тут всё взорвалось.",
  "effect": "explosion",
  "next": "after_bomb"
}
```

### Частицы (`particles` в `scene`)

| Значение | Вид |
|----------|-----|
| `"snow"` | Белый снег |
| `"rain"` | Косые капли дождя |
| `"ash"` | Тёмный пепел (постапокалипсис) |
| `"sakura"` | Розовые лепестки |
| `"fireflies"` | Тёплые светлячки |
| `"none"` | Отключить частицы |

## 🔀 Выборы и ветвления

### Простой выбор

Один узел `choice` — несколько вариантов:

```json
{
  "id": "meet_stranger",
  "type": "choice",
  "options": [
    { "text": "Поздороваться", "flag": "greeted", "next": "greet_scene" },
    { "text": "Пройти мимо", "flag": "ignored", "next": "ignore_scene" }
  ]
}
```

### Ветвление по результату

Через несколько узлов проверяешь флаг:

```json
{
  "id": "check_relationship",
  "type": "branch",
  "cases": [
    { "requires": "greeted", "next": "friend_route" },
    { "requires": "ignored", "next": "stranger_route" }
  ],
  "default": "stranger_route"
}
```

### Ветвление по доверию

```json
{
  "id": "check_trust",
  "type": "branch",
  "cases": [
    {
      "trust": {"Макс": {"op": ">=", "value": 50}},
      "next": "max_good_ending"
    },
    {
      "trust": {"Макс": {"op": "<=", "value": -50}},
      "next": "max_betrayal_ending"
    }
  ],
  "default": "neutral_ending"
}
```

### Пример полной цепочки

```
УТРО → выбор: друг / враг
   │
   ├─ друг ──→ сцена А ──→ (branch по флагам) ──→ ending_good
   │
   └─ враг ──→ сцена Б ──→ (branch по флагам) ──→ ending_bad
```

Подробный пример смотри в `stories/demo/story.json`.

## 🎮 Управление

### В игре

| Клавиша | Действие |
|---------|----------|
| `SPACE` / `ENTER` / клик | Следующая реплика (или скип печати) |
| `ESC` | Меню паузы |
| `F2` | Перечитать `story.json` (горячая перезагрузка) |
| `F5` | Сохранить (быстрое меню слотов) |
| `F9` | Загрузить (быстрое меню слотов) |
| `TAB` | Показать/скрыть HUD (если включён) |

### В меню

| Клавиша | Действие |
|---------|----------|
| `ESC` | Назад |
| Клик | Выбрать |

## ❓ FAQ

### Как запустить игру с другой историей?

Просто создай новую папку в `stories/` с `story.json` — она появится в меню **«Выбрать историю»** автоматически.

### Как менять текст без перезапуска?

Измени `story.json` и сохрани. Через секунду движок подхватит изменения. Если менял картинки — нажми **F2**.

### Не грузится pygame. Что делать?

Используй `pygame-ce`, а не обычный `pygame`:
```bash
pip uninstall pygame
pip install pygame-ce
```

### Программа закрывается сразу. Как увидеть ошибку?

Запусти из терминала:
```bash
python main.py
```

### Куда сохраняются сейвы?

```
saves\<название_истории>\slot_0.json
saves\<название_истории>\autosave.json
```

Отдельная папка для каждой истории. Всё создаётся автоматически.

### Как выложить свою историю на GitHub?

Создай отдельный репозиторий или Pull Request с папкой `stories/<твоя_история>/`. Убедись, что там есть `story.json` и все ассеты.

### Как добавить музыку?

1. Положи `.ogg` или `.mp3` в `stories/<твоя_история>/assets/audio/`
2. Укажи в `scene`:
```json
"music": "assets/audio/bg.ogg"
```

### Как добавить спрайт персонажа?

1. Картинку — в `stories/<твоя_история>/assets/sprites/`
2. В `scene`:
```json
"characters": [
  {
    "name": "Макс",
    "side": "right",
    "images": {
      "neutral": "assets/sprites/max.png",
      "happy": "assets/sprites/max_happy.png"
    }
  }
]
```
3. В `line` переключай эмоцию: `"emotion": "happy"`

### Что если у меня Linux/Mac?

Всё работает так же. Замени `\` на `/` в путях.

### Как поменять разрешение окна?

Открой `engine/config.py`:
```python
WIDTH  = 1280
HEIGHT = 720
```

Или через настройки в игре (полный экран).
